AP & TS OP Performance Report

This AP & TS OP report shows only OP-related data: OP Count & Revenue, Leads and Lead → OP Conversion. OP Revenue is shown directly inside the OP Count & Revenue card. Revenue Need to Achieve is calculated as OP Revenue Target − OP Revenue Achieved. Leads Need to Achieve is calculated as Leads Target − Leads Achieved. This page generates a separate OP report, stores it in a separate OP history sheet, and sends it to a separate OP recipient.

Live Input Sheet

Values are read directly from the live Google Sheet named Input, tab Sheet1, column APTS. No image, Excel or CSV upload is required. The loaded values are automatically filled into the Manual Entry fields below.
